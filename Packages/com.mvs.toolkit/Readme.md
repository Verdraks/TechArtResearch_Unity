
# MVsToolkit

Un ensemble d'outils et utilitaires pour accélérer le développement Unity (éditeur et runtime).

## Description

MVsToolkit fournit des attributs, drawers, utilitaires d'éditeur et composants runtime réutilisables pour Unity. Le package est organisé pour être importé dans un projet Unity via le Package Manager (local ou Git).

## Installation

- Depuis Unity : `Window > Package Manager > + > Add package from disk...` puis sélectionnez le dossier contenant `package.json` de ce package.
- Ou ajoutez le package via une URL Git si vous hébergez ce dépôt publiquement.

## Utilisation rapide

- Parcourez les dossiers `Attributes`, `Editor`, `Runtime`, `Utilities`, etc. pour trouver les composants souhaités.
- Exemples :
	- Attributs personnalisés et PropertyDrawers dans `Attributes/Editor`.
	- Composants de démo dans `Demo/`.

## Structure du package

- `Attributes/` : attributs et drawers.
- `Editor/` : outils d'éditeur et fenêtres.
- `Runtime/` : utilitaires et composants utilisables en runtime.
- `Demo/` : exemples et démonstrations d'utilisation.
